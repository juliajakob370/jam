# 03 - WiFi and now-playing text

Blocked by: 01, 02

## What to build
The board connects to WiFi. It asks Spotify for the current track every few seconds. It shows the song title and artist on the screen.

## Done when
- The screen shows the title and artist of the song that plays.
- The text updates when the song changes.
- The board shows a clear message when WiFi fails or nothing plays.
- The board refreshes the Spotify token before it expires.
- Check that the playback `context` field gives the playlist ID. Write the result in this file.
